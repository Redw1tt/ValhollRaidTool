# Valhöll Raid Tool

Addon World of Warcraft (Retail, interface 12.1.0) pour le suivi des interruptions du joueur et du groupe, avec une interface flat design minimaliste.

## Installation

Copier le dossier dans `_retail_/Interface/AddOns/`.

## Utilisation

- `/vrt` ou `/valholl` : ouvrir/fermer le panneau d'options
- `/vrt reset` : réinitialiser la configuration
