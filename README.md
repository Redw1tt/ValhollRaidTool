# Valhöll Raid Tool

Addon World of Warcraft (Retail, interface 12.1.0) pour des outils de raid, avec une interface flat design minimaliste.

## Modules

- **BossTimelines** — timelines d'événements par boss (Midnight S1 & S2, squelettes à remplir)
- **EncounterAlerts** — alertes de mécaniques par boss
- **AuraTracking** / **AuraSounds** — suivi de buffs/debuffs avec alertes sonores
- **CooldownCheck** — vérification des cooldowns majeurs du groupe
- **Reminders** — rappels configurables (avant pull, ready check, etc.)
- **Nicknames** — surnoms locaux affichés à la place des noms de personnage
- **ReadyCheck** — affichage custom du ready check
- **Assignments** — attribution de rôles/tâches par boss
- **PaceComparison** — comparaison du temps de pull actuel au meilleur temps enregistré
- **WAImports** — chaînes d'import WeakAuras pré-configurées
- **VersionCheck** — version locale de l'addon (sync réseau à venir)

Chaque module peut être activé/désactivé dans le panneau d'options (`/vrt`).

## Installation

Copier le dossier dans `_retail_/Interface/AddOns/`.

## Utilisation

- `/vrt` ou `/valholl` : ouvrir/fermer le panneau d'options
- `/vrt reset` : réinitialiser la configuration
